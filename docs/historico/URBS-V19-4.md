# URBS V19.4 — Mapa Holográfico

## O que foi implementado
- Substituição da experiência anterior por um **mapa holográfico 2.5D** em Three.js.
- Controles visuais de **DIA / TARDE / NOITE**.
- Botão **VISÃO AÉREA** para retorno ao enquadramento geral.
- Botão **VISUALIZAR RUA EXATA** para aproximar a câmera de um trecho urbano selecionado.
- Marcadores urbanos interativos com painel informativo.
- Manutenção da identidade visual do URBS, dos carrosséis e das demais páginas.

## Estrutura principal alterada
- `public/index.html`
- `public/assets/js/urbs-holographic-map-v19-4.js`
- `public/assets/css/urbs-holographic-map-v19-4.css`

## Observação
A cena é **conceitual e demonstrativa**, pensada para reforçar a proposta visual do projeto sem depender de API externa.
