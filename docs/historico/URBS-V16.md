# URBS V16 — Território interativo e carrosséis restaurados

- Base: V14 (mantém os dois carrosséis horizontais automáticos, incluindo o efeito WebGL Liquid Hover).
- Seção geográfica: CesiumJS + Esri World Imagery; câmera 3D, filtros dos dados de store.js, pinos e tour.
- Alternativa: mapa satélite interativo com Leaflet quando Cesium não carregar.
- Não requer API key do Google. Credencial Google anterior foi removida do ZIP.
- Dados de demonstração são fictícios; registros do usuário ficam somente no navegador.
- Renderização em 3D usa superfície elipsoidal, não modelos fotorrealistas de edifícios.
- Carrosséis preservados: categorias e Observe/Localize/Acompanhe, loop horizontal, sem setas.
- Teste no XAMPP em http://localhost/urbs/public/index.html.
